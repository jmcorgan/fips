# The XX flow's incidental rules: each rule, or part of a rule, of next's handshake
# settlement whose outcome no clause of FRC-2201 and no decision with a reason fixes.
# Class I has no record at all; class I-kept is kept as next's node has it by a record
# that gives no reason on the merits. A rule FRC-2201 requires, or a decision fixes, is
# not listed, and its tests are not marked. Neither is a known defect whose fix is
# planned: its test is pinned, not marked.
#
# A test that asserts one of these outcomes records current behaviour, not a
# requirement: current.txt lists it, and its doc comment says so. Changing such an
# outcome is a decision, made with this file, current.txt and the tests in one change,
# not a regression. A rule that a decision fixes leaves this file, and its tests leave
# current.txt and lose their doc line, in the change that records the decision.
#
# One line per rule: its ID, its class, `tested` when current.txt lists a test for it
# or `untested` when none asserts it, and the incidental part with its record. The
# settlement core's own list is ../../settle/rules.txt, with IDs S-NN; these are XX-NN.
# `src/node/settle/tests/rules.rs` checks this file against current.txt and the tests.
XX-01  I-kept  tested    the larger node that keeps the session it holds at its own msg2, by address order, still sends msg3; FRC-2201 Section 5.7 is silent; kept as next's node has it
XX-02  I-kept  tested    the restart gate at msg3 counts the peering's idle time from its install as well as from its last frame, so a peering installed under 15 s ago that carried no frame refuses a restart; FRC-2201 Section 5.6's first gate counts frames only; kept as next's node has it
XX-03  I-kept  tested    the silent-session values: a refusal from the third silent session in a row at one epoch, 30 s, doubling to 600 s, a record lapsing after 600 s; kept as next's node has it
XX-04  I-kept  tested    the retry after a failure at msg2 goes to the identity the leg expects by then: the one its completion learned, else the one the msg2 taught, else the one the dial named; an anonymous dial that learned no one retries no one; kept as next's node has it
XX-05  I-kept  tested    a leaf node refuses a second peer at msg2 and at msg3 and removes the refused link at once, where the max-peers cap leaves it for the reap; kept as next's node has it
XX-06  I-kept  tested    the own-dial keep offers the msg2's pair to the held peer's link as a heard path; kept as next's node has it
