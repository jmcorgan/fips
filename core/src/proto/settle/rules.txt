# The settlement core's incidental rules: each rule, or part of a rule, whose
# outcome no FRC clause and no decision with a reason fixes. Class I has no
# record at all; class I-kept is kept as the node had it by a record that
# gives no reason on the merits. A rule an FRC clause requires, or a decision
# fixes, is not listed, and its tests are not marked.
#
# A test that asserts one of these outcomes records current behaviour, not a
# requirement: current.txt lists it, and its doc comment says so. Changing
# such an outcome is a decision, made with this file, current.txt and the
# tests in one change, not a regression. A rule that a decision fixes leaves
# this file, and its tests leave current.txt and lose their doc line, in the
# change that records the decision.
#
# One line per rule: its ID, its class, `tested` when current.txt lists a test
# for it or `untested` when none asserts it, and the incidental part with its
# record. `src/node/settle/tests/rules.rs` checks this file against
# current.txt and the tests.
