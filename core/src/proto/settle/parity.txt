# What a node holds after each step of each shared schedule, read by
# `parity.rs` (see its doc for the format and what reads it).
#
# A block opens `script <name> <setting per node>`. Each line after it is
# `<step> n<node> <mark>`: `none`, or `held` and whose dial the current
# session came from (own, peer), the link record's direction (in, out),
# the pair it was set up at, the pair the end sends on, and whether the
# end counts the peering heard. A pair is a transport and which of the
# peer's addresses it reaches: its home, its second, or `accepted`, the
# source of a connection the peer opened. A `core` line states a field the
# settlement core gives differently at that step and end, and the node's
# defect it comes from.
#
# Source of this file's first version, the two crossings (starts 1 and 3 of
# the settlement tests), each in both address orders and at both settings:
#
# - The core's lines: FRC-1201 Section 5.6. The smaller node moves onto its
#   own dial's session, takes the msg2's source as the peer's address and
#   holds the link as the link it dialed, set up at the address it dialed;
#   the larger keeps its inbound handshake. The joint world's
#   `a_crossing_settles_on_one_session_on_real_machines` and
#   `a_crossing_on_a_connection_oriented_transport_leaves_the_smaller_node_at_its_dials_pair_on_real_machines`
#   assert the same.
# - The node's lines: the model of the node in the settlement tests,
#   whose crossed dials leave the smaller node on the link the larger
#   dialed (`legacy/findings.rs`, the two crossings, smaller node first),
#   at the pair it dialed: the node's own
#   `crossed_tcp_dials_leave_the_smaller_node_on_the_link_it_dialed_*`
#   pins hold the same of a real node. A move does not set a peering
#   heard; a peering promoted on a msg1 is unheard until a frame arrives.
# - Both read line by line against a run of the model of the node and of
#   joint nodes on these schedules at both settings, which gave these
#   lines; the joint nodes' `session` there was read from the handshake
#   their current session came from.
