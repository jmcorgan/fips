# What the master commit last merged into next has and next does not, each with why.
# Checked by testing/check-carried.py, which reads master's tests, mutation-lane switches and
# known-defect entries at that commit and fails on any that is neither on next nor listed here,
# and on any entry that is no longer true either way. Lives on next only.
#
# Fields, separated by whitespace:
#   kind    test          a test function, by bare name
#           switch        a variant of core/src/faults.rs's faults! list
#           known-defect  a known-defect entry of testing/ignored-tests.txt, by test path
#   class   no-site       the code the item exercises is not on next
#           next-rule     the code is on next and next's rule differs from master's
#           replaced      next holds a counterpart that tests the same site; the fifth
#                         field names it, a test (or for a switch, a switch) next holds
#           open          not yet classed; the check lists every such entry, and it is
#                         settled at or before the next merge
#   name    the item, as master names it
#   file    where the merged master holds it
#   target  for replaced only
#
# A merge into next that brings an item adds it here or carries it; a merge that carries one
# removes its line. The check cannot say a reason is true: the merge's review does.
#
# Left off next and outside the check's kinds, so recorded here as comments only: master's
# chaos edge agreement on crossed edges. tcp-mesh dials four edges from both ends on master
# and keeps every edge one-way on next, with no min_crossings floor; churn-mixed's
# edge_agreement block is not on next; and the agreement break lane (agreement-break in
# testing/ci-local.sh) is off in next's default run. On next a crossed edge has been seen to
# end with both ends listing it outbound, and the crossing clause's rule, the smaller node on
# its own dial, is not next's after a refusal. All three return when next's crossing is
# settled.
